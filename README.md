# Sentiment Analysis on IMDb Reviews

This is a small project that fetches reviews from IMDb and then runs sentiment analysis on them.  
It uses **Flask** for the backend and **NLTK (VADER)** to figure out whether a review is positive, negative, or neutral.
And displays the results accordingly.

---

## Features
- Fetches IMDb reviews  
- Cleans and processes the text  
- Runs sentiment analysis with NLTK  
- Provides results through a simple Flask API  

---

## Tech Stack
- Python 3  
- Flask + Flask-CORS  
- NLTK  
- Pandas  
- BeautifulSoup4  
- Requests  

---

## Project Structure

- data/ → contains the dataset (CSV files or any raw data used). 
- src/ → main source code for training, preprocessing, and evaluation.    
- README.md → this file.  
- requirements.txt → list of dependencies needed to run the project.
